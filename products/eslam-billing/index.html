Eslam Billing

An ISP operations platform concept for subscriber onboarding, hotspot and PPPoE billing, vouchers, router operations and payment workflows in UGX. The current hosted build is a user-interface/PWA preview, not a production billing service.

Platform scope

Subscriber operations

ISP onboarding, customer records, service plans, invoices and subscriber lifecycle workflows.

Payments and vouchers

Designed for UGX workflows, including MTN MoMo, Airtel Money, cash agents and hotspot vouchers. Provider activation is not yet confirmed.

Network operations

Planned MikroTik, PPPoE, hotspot and RADIUS integrations, with access controls and operational diagnostics.

Install on a phone

Use the web app like an app

  1. Open the Eslam PWA preview in Chrome on Android or Safari on iPhone.
  2. On Android, open the browser menu and choose Install app or Add to Home screen.
  3. On iPhone, tap Share, then Add to Home Screen.
  4. Launch Eslam Billing from the new home-screen icon.

The PWA caches its static app shell only. Authenticated API requests and customer data are deliberately excluded from offline caching. Offline installation does not mean billing, payment processing or router operations work offline.

Readiness and safety

Preview, not production billing

The repository includes Firebase authentication and an Express API foundation, but the current Vercel preview is not proof that the production API, Firebase Admin credentials, Firestore rules, payment provider callbacks or RADIUS/router integrations are live. Dashboard sections may still contain sample data.

Do not use this preview to collect real customer payments, store production subscriber records, or change live router settings. Those workflows must be deployed and tested end-to-end before operational use.
