Build status

Development is public and traceable.

Database foundation completed 27 November 2026: isolated workspace tables, row-level security and private PDF/TXT storage are in place. The private app build now includes account access, workspace creation and document upload. Two JWT-protected backend functions are deployed for PDF/TXT text extraction, searchable indexing, workspace-scoped Gemini answers and source references. Gemini secret configuration and end-to-end testing with real sample documents are still required. Scanned PDF OCR, document deletion workflows and the production security review remain before public launch. We publish engineering changes through the BINBAWY TECH UG website.
